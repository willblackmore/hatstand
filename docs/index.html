What it does

Separate instances

Each instance has its own sign-in, chats, settings, MCP servers and Claude Code data. Nothing leaks between them.

One click to switch

Pick an instance from the menu. Hatstand quits Claude fully, then reopens it as the one you chose.

Leaves Claude alone

Hatstand never modifies Claude or moves its data. It only launches Claude with the right settings for each instance.

Install

  1. Download Hatstand.dmg, open it and drag Hatstand into Applications.
  2. Open Hatstand. The first time, macOS says it can't check the app for malicious software. Click Done.
  3. Open System Settings › Privacy & Security, scroll down to the message about Hatstand and click Open Anyway.
  4. Hatstand appears in your menu bar. Open Manage Instances… and click + to add your second account.

Why the extra step? Hatstand is a free hobby project and isn't signed with a paid Apple Developer ID, so macOS asks you to confirm you trust it. You only need to do this once. You can also build it yourself from the source code.
